# Code Review Skill

A helpful skill for reviewing code quality and identifying improvements.

## Instructions

1. Read the provided code carefully and understand its purpose.
2. Identify potential bugs, logic errors, and edge cases.
3. Check for adherence to project conventions and style guides.
4. Suggest clear, actionable improvements.
5. Provide constructive and specific feedback.

## Output Format

- Start with a brief summary of the code's purpose.
- List findings grouped by severity: critical, high, medium, low.
- End with a positive note about what the code does well.
