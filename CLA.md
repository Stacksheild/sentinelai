## Why a CLA?

SentinelAI uses a dual-license model: free for non-commercial use under
PolyForm Noncommercial 1.0, with separate commercial licenses available.

The CLA ensures that Stacksheild can:

1. Continue offering SentinelAI under the PolyForm Noncommercial License
2. Offer commercial licenses to businesses that need them
3. Relicense if needed (e.g., if the community decides to change licenses)
4. Defend the Project against IP claims

Without a CLA, any contributor could block relicensing, which would make
the dual-license model unsustainable.

**This is the same approach used by MongoDB, Elastic, HashiCorp, Apache
Software Foundation, and many other successful open-source projects.**

Your contributions remain yours. You can use them anywhere else. We just
need the right to include them in all versions of SentinelAI.
